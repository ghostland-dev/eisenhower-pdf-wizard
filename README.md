# Eisenhower Matrix

Prioritise tasks by urgency and importance, then export to PDF.

## Features

- Colour-coded quadrants
- Quick task entry
- PDF export

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- jsPDF

## Getting Started

```bash
git clone https://github.com/ghostland-dev/eisenhower-pdf-wizard.git
cd eisenhower-pdf-wizard
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
